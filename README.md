# Siam Chat — เว็บไซต์หน้าแรก

เว็บ: https://eskimooo1234-maker.github.io/siamchat/

## แก้ข้อความ / ลิงก์

เปิด `index.html` แล้วดูส่วน `<script>` ด้านบนสุด (ใต้ `<link href="https://fonts...">`)

- `LINKS` — ลิงก์ Facebook / TikTok / LINE · ใส่ลิงก์แล้วปุ่มจะขึ้นเอง · เว้น `''` = ซ่อน
- `DOWNLOAD` — ส่วน "เริ่มใช้ 3 ขั้น" (id="install"): ข้อความขั้นที่ 1–3, ลิงก์ และหมายเหตุ
  (`groupUrl` = ลิงก์กลุ่ม Google Group · `playUrl` = ลิงก์ทดสอบ · `storeUrl` = หน้าแอปใน Play Store)

ข้อความอื่น ๆ (หัวข้อ, การ์ด) แก้ตรงในเนื้อ HTML ได้เลย

## ภาพหน้าจอแอป

วางไฟล์ชื่อ `assets/screen-1.png` (แนวตั้ง สัดส่วนประมาณ 9:19) แล้วภาพจะขึ้นในกรอบมือถือแทนภาพจำลองเอง

## ไฟล์

- `index.html` — ทั้งหน้า (CSS อยู่ในไฟล์)
- `assets/logo-64.png`, `logo-128.png` — โลโก้
- `assets/favicon-32.png`, `apple-touch-icon.png` — ไอคอนแท็บ/หน้าจอโฮม
- `assets/og.png` — ภาพตอนแชร์ลิงก์ (1200×630)
- `assets/districts.json` — 4 ภาค / 77 จังหวัด / 928 อำเภอ-เขต: ชื่อไทย + ภาค + จังหวัด + พิกัดกึ่งกลาง (ใช้กับช่องค้นหาและแผนที่)
  export จาก `src/data/provinces.ts` + `src/data/districts.ts` + migration `districts_center_radius_seed` ของแอป
  พิกัด: OpenGISData-Thailand (CC BY 4.0) · ศูนย์กลางจังหวัด = อ.เมือง (กรุงเทพฯ = เขตพระนคร) · อ.เมืองเชียงใหม่ ใช้จุดคูเมือง 18.7883, 98.9853
- แผนที่: Google Maps JavaScript API — กุญแจอยู่ที่ `MAPS.key` ใน `<script>` ด้านบน (จำกัดโดเมนไว้ที่ Google Cloud)
  โหลด 1 ครั้งต่อการเปิดหน้า (ตอนเลื่อนถึงการ์ด) · เปลี่ยนพื้นที่/แท็บ/ระยะ = ย้ายกล้อง ไม่สร้างแผนที่ใหม่
  ถ้าโหลดไม่ได้ (ชนเพดาน/กุญแจผิด/ไม่มีเน็ต) จะแสดงกล่อง "ดูแผนที่จริงได้ในแอป" แทน
  หมุดทั้งหมดเป็นตัวอย่างที่สร้างในหน้าเว็บ (ไอคอน/หมวดตาม `rooms.ts` ของแอป) ไม่ใช่ข้อมูลจาก DB
- `assets/icons/` — ไอคอนหมวดแบบภาพของแอป: ชาเย็น (เครื่องดื่ม) และแผงตลาดสด (แปลงจาก `CategoryIcon.tsx`)

## ลองใช้แอป (แอปจำลอง)

- ปุ่ม "▶ ลองใช้แอป" ใต้การ์ดแผนที่ และ "⤢ ขยายเต็มจอ" มุมแผนที่ → เปิดแอปจำลองเต็มจอ (จอคอม = กรอบมือถือกลางจอ)
- ไฟล์ `demo.css` / `demo.js` / `demo-data.js` โหลดตอนกดครั้งแรกเท่านั้น (หน้าแรกยังเบา)
- แก้ข้อความ/โพสต์/เหตุตัวอย่าง/เมนูโปรไฟล์ที่ `demo-data.js` ไฟล์เดียว · ข้อมูลทั้งหมดเป็นตัวอย่าง ไม่เรียก DB/API ไม่เก็บอะไร
- **แก้ไฟล์ demo แล้วต้องเปลี่ยนเลข `var V = '?v=…'` ใน `index.html`** ไม่งั้นเบราว์เซอร์อาจใช้ไฟล์เก่า
- แท็บแผนที่ใช้แผนที่ตัวเดิมของหน้าเว็บ (ย้ายเข้าไป) → ยังโหลดแผนที่ 1 ครั้งต่อการเปิดหน้า · ในแอปจำลองลากด้วยนิ้วเดียวได้
- `assets/avatars/` — รูปสัตว์ชุดเดียวกับแอป (Noto Emoji, Apache 2.0 — ดู LICENSE-NOTO-EMOJI.txt) ย่อเหลือ 96px
